Mock a client in a test:

```go
ias, err := cassette.InteractionsReadFile("testdata/interactions.json")
if err != nil {
	t.Fatal(err)
}

client := &http.Client{Transport: cassette.Replay(ias)}
```

A client generated by
[openapi-codegen](https://github.com/MarkRosemaker/openapi-codegen) takes it as
`WithHTTPClient(&http.Client{Transport: cassette.Replay(ias)})`.

Record what has no recording yet, and save it:

```go
rec := cassette.Replay(ias, cassette.RecordMisses(nil))
client := &http.Client{Transport: rec}

// … make the calls …

if err := rec.Interactions().WriteFile("testdata/interactions.json"); err != nil {
	return err
}
```

Check every call against its recording, in order and with its headers:

```go
rec := cassette.Replay(ias, cassette.InOrder(), cassette.WithMatcher(
	cassette.MatchRequest(cassette.CompareHeaders("User-Agent")),
))

t.Cleanup(func() {
	if unused := rec.Unused(); len(unused) > 0 {
		t.Errorf("%d recordings were never replayed", len(unused))
	}
})
```

The package examples run each of these.
